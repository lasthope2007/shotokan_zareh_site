# آکادمی کاراته شوتوکان زارع — Full-stack starter

پروژه بر پایه Next.js 14 + TypeScript + PostgreSQL + Prisma ساخته شده است. ظاهر فارسی راست‌چین با الهام از ژاپن، پنل ورود مدیر، دیتابیس واقعی، مقالات، افتخارات، هنرجویان، گالری و فرم تماس دارد.

## پیش‌نیازها
- Node.js 20 یا جدیدتر
- PostgreSQL محلی یا یک دیتابیس میزبانی‌شده مانند Neon
- npm

## راه‌اندازی در Windows 11
1. ZIP را استخراج کن و در همان پوشه ترمینال باز کن.
2. `npm install`
3. `.env.example` را به `.env` کپی کن.
4. مقدارهای `DATABASE_URL`, `AUTH_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` را تنظیم کن.
5. دستورات زیر را اجرا کن:

```powershell
npx prisma generate
npx prisma migrate dev --name init
npm run db:seed
npm run dev
```

6. سایت: `http://localhost:3000`
7. ورود مدیر: `http://localhost:3000/admin/login`

## امنیت
- رمز مدیر با bcrypt هش می‌شود و نشست در کوکی HttpOnly قرار می‌گیرد.
- `AUTH_SECRET` را حتماً با مقدار تصادفی طولانی جایگزین کن.
- `.env` را هرگز در GitHub قرار نده.
- قبل از انتشار عمومی، محدودسازی تلاش ورود، rate limit فرم تماس، مدیریت کامل CRUD، بارگذاری امن تصاویر، سیاست حریم خصوصی و تست امنیتی را اضافه کن.
- هیچ رمز پیش‌فرضی را روی سایت عمومی استفاده نکن.
